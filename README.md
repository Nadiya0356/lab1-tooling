# Лабораторна робота №1: Налаштування Go Tooling

## 📌 Опис

У цій лабораторній роботі виконано налаштування середовища розробки для мови Go, зокрема:

* створено структуру проєкту відповідно до Standard Go Layout
* реалізовано базові функції
* написано модульні тести (table-driven tests)
* підключено статичний аналіз коду (golangci-lint)
* автоматизовано процеси за допомогою Makefile

---

## 📁 Структура проєкту

```
lab1-tooling/
│
├── cmd/app/main.go        # Точка входу
├── internal/math.go       # Основна логіка
├── internal/math_test.go  # Тести
├── Makefile               # Автоматизація
├── .golangci.yml          # Конфігурація лінтера
├── go.mod                 # Опис модуля
├── README.md              # Документація
```

---

## ⚙️ Вимоги

* Go 1.21 або новіше
* golangci-lint
* make (опціонально для Windows)

---

## ▶️ Запуск

### Запуск тестів

```
go test -v ./...
```

### Запуск тестів з перевіркою race condition

```
go test -race ./...
```

### Перевірка коду лінтером

```
golangci-lint run
```

### Форматування коду

```
go fmt ./...
```

### Збірка проєкту

```
go build ./cmd/app
```

### Виконати все (через Makefile)

```
make all
```

---

## 🧪 Тестування

У проєкті використано табличні тести (table-driven tests) із пакету `testing`.
Перевіряються як стандартні випадки, так і крайові (наприклад, ділення на нуль).

---

## 🔍 Статичний аналіз

Для перевірки якості коду використовується **golangci-lint** з підключеними лінтерами:

* errcheck
* gosimple
* unused
* revive
* staticcheck

---

## ⚠️ Примітки

* Для використання прапора `-race` може знадобитися CGO та GCC (особливо у Windows)
* Антивірус Windows Defender може блокувати створення .exe файлів (це не помилка коду)

---

## 🧠 Висновок

У ході лабораторної роботи було налаштовано середовище розробки для Go,
включаючи тестування, статичний аналіз та автоматизацію.
